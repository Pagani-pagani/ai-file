AI File v1 — 檔案清單
========================

根目錄
  agent.md              專案說明（架構、安全模型、流程、版本歷史）
  README.md             安裝與使用說明
  VERSION               版本號（目前是 1）
  .gitignore            ai-file-config.json、ai-file-log.txt 絕不進版控

web/（GitHub Pages 網站，全部繁體中文）
  index.html            靜態 SPA：管理員登入、AI 登入、待同步、異動紀錄、下載區
  app.js                呼叫 GitHub API 讀寫中繼 repo（金鑰只存瀏覽器 localStorage）
  style.css             介面樣式

agent/（Windows 本地端，Python 標準函式庫，不用 pip）
  ai_file_agent.py      本地端主程式：設定精靈、輪詢、通知、浮動視窗、立即同步
  啟動 AI File.bat      主要啟動器（pythonw.exe，不跳黑視窗）
  啟動 AI File.vbs      備援啟動器
  自我檢查.py           自我檢查：設定檔、路徑守門、雜湊驗證、停止旗標、同步流程
  檔案清單.txt          就是這個檔案

不會出現在 GitHub 上的檔案（只存本機）
  ai-file-config.json   你的 PAT、允許的資料夾、工作階段代碼
  ai-file-log.txt       本機同步紀錄
